# Практика 10. Разработка интерфейса пользователя

## Что сделано

Сверстала все страницы по требованиям из практики 6 на HTML, CSS и JavaScript (серверные шаблоны EJS в `portal/views`, стили `portal/public/css/style.css`, скрипт `portal/public/js/app.js`):

- главная: вводный блок с фото, афиша карточками, ниже прошедшие мероприятия (чёрно-белые фото, пометка «Мероприятие прошло»);
- страница мероприятия: фото, дата и место, описание, кнопка заявки; у прошедшего мероприятия вместо кнопки пояснение;
- регистрация и вход: форма в карточке, ошибка под полем, кнопка «Показать пароль»;
- заявка с выпадающими списками, мои заявки с карточками и формой отзыва;
- личный кабинет (`/cabinet`): данные пользователя и три счётчика;
- панель администратора: фильтр и карточки заявок со сменой статуса;
- страницы ошибок 403 и 404 в общем оформлении.

Шрифты Literata и Onest лежат в `public/fonts` (лицензия OFL), с чужих сайтов ничего не загружается. Фото сжаты (список в `docs/photo_sources.md`), у картинок есть `srcset` для телефона и компьютера.

JavaScript минимальный: кнопка меню на телефоне и показ пароля. Всё остальное работает без скриптов.

## Адаптивность

Три раскладки: до 640 px (телефон: меню за кнопкой, карточки по одной, кнопки на всю ширину), до 900 px (планшет: две колонки), шире (три колонки). Кнопки и поля не ниже 44 px, шрифт в полях 16 px.

Проверила ширину содержимого скриптом на всех страницах (включая закрытые для гостя) при ширинах 320, 390, 768 и 1280 px: горизонтальной прокрутки нет ни на одной.

## Кроссбраузерность

Открыла главную и панель администратора в двух браузерах: Google Chrome 156.0.8078.80 (снимки `01`-`06`) и Microsoft Edge 156.0.4314.58 (`07`, `08`). Страницы выглядят одинаково. Firefox и Safari на компьютере не установлены, в них не проверяла. Chrome и Edge работают на одном движке (Chromium), поэтому это проверка только в двух браузерах, но не на разных движках.

## Телефон 390x844

Снимки `09`-`13` сделаны в Chrome в режиме эмуляции телефона 390x844: главная, открытое меню, мероприятие, мои заявки, заявка. Настоящего смартфона под рукой не было.
