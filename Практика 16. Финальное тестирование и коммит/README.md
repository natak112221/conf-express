Проверяла в отдельном репозитории [conf-express-qa](https://github.com/natak112221/conf-express-qa) (МДК.05.03): руками по тест-кейсам, скриптами `check_forms.py` (45 проверок) и `check_flows.py` (20 проверок), автотестами Selenium (15 тестов). Версия портала до исправлений: коммит `4a86f35`.

## Найденные ошибки

Девять, все настоящие, найдены прогонами. Подробные баг-репорты со скриншотами в `conf-express-qa`, задание 1.

| ID | Ошибка | Исправление |
|---|---|---|
| BR-01 | логин `Ivan_K` принят при существующем `ivan_k` | уникальный индекс без учёта регистра (миграция 006), поиск логина без учёта регистра |
| BR-02 | пароль из 8 пробелов принят | проверка пароля в `src/lib/validate.js` |
| BR-03 | почта из 300 символов принята и ломает ширину страницы на телефоне | не больше 254 символов |
| BR-04 | пароль длиннее 72 байт усекается (bcrypt), вход с другим окончанием проходит | пароль больше 72 байт отклоняется |
| BR-05 | слишком большой запрос даёт 500 вместо 413 | обработчик ошибок берёт код 4xx из ошибки |
| BR-06 | заявку на прошедшее мероприятие можно подать по прямому адресу | проверка даты на сервере, ответ 422 |
| BR-07 | заявку на будущее мероприятие можно завершить | завершить можно только после мероприятия |
| BR-08 | статус можно вернуть назад | допустимы текущий и следующий статусы |
| BR-09 | личные страницы без `Cache-Control: no-store` | заголовок для вошедшего пользователя |

Исправления в трёх коммитах («Практика 16: ...»), на каждую ошибку добавлен тест в `portal/tests` (29 тестов в проекте).

При повторном прогоне увидела в выводе тестов ошибку `path is not defined`: первое исправление BR-05 возвращало 413, но страница ошибки не рисовалась, потому что запрос обрывался раньше, чем в шаблоны подставлялся пользователь (так же, как в практике 5). В обработчике ошибок добавила значения по умолчанию, а тест теперь проверяет и текст страницы.
