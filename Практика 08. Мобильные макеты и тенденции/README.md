# Практика 8. Дизайн с учётом современных тенденций, мобильные макеты

## Тенденции, которые взяла

1. Минимализм: один акцентный цвет (ягодный #8F2D56), светлый тёплый фон, много свободного места, на экране одно главное действие.
2. Карточный дизайн: мероприятия и заявки лежат в белых карточках с тонкой рамкой. У мероприятия слева «корешок билета» с крупной датой.
3. Микро-взаимодействия: карточка и кнопка слегка сжимаются при нажатии, у поля при фокусе появляется обводка, у пункта нижней панели активная страница отмечена полоской сверху.

## Макеты 390x844

Сделала шесть отдельных `.html` файлов в папке `mobile/` с общим стилем `css/mobile.css`:

| Файл | Страница |
|---|---|
| `index.html` | афиша: фото, список мероприятий карточками |
| `event.html` | мероприятие: фото, дата и место, описание, кнопка заявки |
| `apply.html` | заявка: помещение и способ оплаты выбираются из списков |
| `my.html` | мои заявки: карточки со статусами «новая», «назначено», «завершено» |
| `login.html`, `register.html` | вход и регистрация |

Меню в шапке сделано на элементе `<details>`, без скриптов. Внизу панель из трёх разделов, как в мобильных приложениях. Кнопки и поля 48 px высотой, шрифт в полях 16 px, чтобы телефон не увеличивал страницу при вводе.

## Оптимизация картинок

Фото взяла на pexels.com (номера в `docs/photo_sources.md` в корне репозитория). Скачала версии шириной 1800 px, обрезала до 3:2 и сжала до 780 px (в два раза шире экрана телефона, чтобы было чётко на экранах с плотностью 2x), JPEG качество 78.

| Фото | Исходник, КБ | Для телефона 780 px, КБ |
|---|---|---|
| hero-m.jpg (афиша) | 276 | 52 |
| design-m.jpg | 202 | 55 |
| testing-m.jpg | 408 | 49 |
| mobile-m.jpg | 306 | 37 |
| db-m.jpg | 503 | 95 |

Картинки в карточках загружаются лениво (`loading="lazy"`), у всех заданы `width` и `height`, чтобы страница не прыгала при загрузке.

## Проверка на 390x844

Открыла все шесть файлов в Chrome в режиме эмуляции телефона 390x844, плотность 2. Ширина содержимого равна ширине экрана (390 из 390), горизонтальной прокрутки нет, нижняя панель не закрывает текст (у страниц отступ снизу 76 px). Настоящего смартфона под рукой не было, поэтому проверка только в эмуляции.
