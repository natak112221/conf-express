# Практика 6. Формирование требований к дизайну веб-приложения

## Аудитория

- Участники: студенты и специалисты 18-45 лет. Заходят с телефона по дороге и с ноутбука дома. Хотят за 1-2 минуты найти мероприятие и подать заявку. Опыт работы с сайтами разный, поэтому формы должны объяснять себя сами.
- Администраторы: 2-3 человека из команды организатора. Работают с компьютера, весь день смотрят на таблицу заявок. Им нужен список, где статус и фильтр видны сразу.

## Корпоративный стиль заказчика

Организатор говорит о себе просто и по-деловому, без «экспертных» слов. Встречи небольшие, живые, поэтому сайт должен выглядеть как афиша: крупная дата, название, место.

| Элемент | Решение |
|---|---|
| Основной цвет | ягодный (бордо) #8F2D56, для кнопок и ссылок |
| Текст и тёмные блоки | графит #22252D |
| Фон страницы | тёплый светлый #F7F4F0, карточки белые |
| Линии и рамки | песочный #E4D9CC |
| Приглушённый текст | сланцевый #5B6170 |
| Заголовки | Literata (с засечками), 600 |
| Основной текст | Onest, 16 px, межстрочный 1,5 |
| Форма элементов | углы 6 px, кнопки без градиентов, дата мероприятия крупной цифрой |
| Фото | реальные снимки мероприятий и залов, тёплые, без людей крупным планом |
| Тон текстов | на «вы», короткие предложения, без восклицаний |

Статусы заявок различаются не только цветом, но и словом: «новая» (серый), «назначено» (бордовый светлый), «завершено» (графитовый).

## Страницы для дизайна

Регистрация, авторизация, просмотр заявок (мои заявки), создание заявки, панель администратора, личный кабинет. Дополнительно: главная со списком мероприятий, страница мероприятия, страницы ошибок 403 и 404.

## Требования к страницам

| Страница | Что на ней | Особые требования |
|---|---|---|
| Регистрация | логин, пароль, почта, телефон | ошибка под каждым полем, подсказка формата, пароль можно показать |
| Авторизация | логин, пароль | одно общее сообщение об ошибке, отдельная ссылка на регистрацию |
| Мои заявки | карточки заявок: мероприятие, дата, помещение, оплата, статус | у завершённой заявки форма отзыва, у остальных пояснение, когда она появится |
| Создание заявки | мероприятие, помещение, способ оплаты | помещение и оплата выбираются из списков, на странице видно название и дату мероприятия |
| Панель администратора | карточки заявок, фильтр по статусу и мероприятию, смена статуса | статус меняется в карточке, фильтр над списком, счётчик найденных заявок |
| Личный кабинет | данные пользователя, число заявок, ссылки на заявки | телефон и почта показаны, пароль не показывается |
| Главная | афиша мероприятий карточками | крупная дата, название, место, кнопка «Подробнее» |
| Мероприятие | фото, описание, дата, место, кнопка заявки | у прошедшего мероприятия вместо кнопки пометка «Мероприятие прошло» |
| Ошибки | код, одно предложение, ссылка на главную | в общем оформлении сайта |

## Общие требования

- Ширины для проверки: 390, 768 и 1280 px; на 390 px нет горизонтальной прокрутки.
- Кнопки и поля не ниже 44 px, шрифт в полях не меньше 16 px.
- Контраст основного текста не ниже 4,5 к 1.
- Меню на телефоне открывается кнопкой, форму можно заполнить одной рукой.
- Шрифты лежат на сервере, не загружаются с чужих сайтов.
- Картинки сжаты, вес главной страницы не больше 600 КБ.
- Работает при отключённой анимации (`prefers-reduced-motion`).
