# conf-express

Учебный портал «Конференции.РФ» для МДК.09.01 «Проектирование и разработка веб-приложений». Афиша встреч для разработчиков в Москве: гость смотрит мероприятия и регистрируется, участник подаёт заявки и оставляет отзывы, администратор ведёт заявки по статусам. Отчёт: `Отчет МДК.09.01.docx`. Тестирование портала в репозитории [conf-express-qa](https://github.com/natak112221/conf-express-qa).

Стек: Node.js 22, Express 5, шаблоны EJS, SQLite (better-sqlite3), express-session, bcryptjs, helmet. Классы моделей и контроллеров, маршруты в `src/routes`, миграции базы в `db/migrations`.

## Запуск

```
cd portal
npm install
npm run setup
npm start
```

Сайт откроется на http://localhost:8102 (порт меняется переменной `PORT`). `npm run setup` создаёт базу в `portal/data` и добавляет тестовые данные. Тесты: `npm test`, проверка кода: `npm run lint`.
