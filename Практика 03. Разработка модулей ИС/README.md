# Практика 3. Разработка модулей ИС по ТЗ

## Что сделано

Создал проект `portal/` и разделил его на части:

- `views/` и `public/` - страницы (EJS) и стили, это фронтенд;
- `src/` - маршруты, контроллеры, модели и проверки, это бэкенд;
- `db/` - миграции и тестовые данные (SQLite, библиотека better-sqlite3).

Код на классах: у каждой таблицы свой класс модели (`UserModel`, `EventModel`, `ApplicationModel`), у каждого раздела свой контроллер (`AuthController`, `EventController`, `ApplicationController`, `AdminController`). Маршруты собраны в `src/routes/index.js`.

Модули:

- регистрация: логин уникальный (3-20 символов, латиница, цифры, _), пароль от 8 символов, почта и телефон по шаблону;
- вход и выход;
- создание заявки: мероприятие, помещение, способ оплаты, на мероприятие одна заявка;
- список своих заявок;
- панель администратора: все заявки и смена статуса (новая, назначено, завершено).

## Как проверил

Прошёл все сценарии в браузере (скриншоты в этой папке): список мероприятий, регистрация с ошибками и без, заявка, мои заявки, вход под администратором, смена статуса, переход гостя на страницу входа.

## Что пока сделано просто

Пароли лежат в базе как есть, форм без защиты от подделки запроса нет, cookie сессии стандартные. Это исправляю в практике 4.

## Запуск

```
cd portal
npm install
npm run setup
npm start
```

Сайт откроется на http://localhost:8102. Тестовые входы: admin / Admin2026, ivan_k / Password123.
